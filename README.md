# 💰 SpendiQ – Expense Tracking & Analytics Dashboard

SpendiQ is a Python-based personal expense tracking and analytics dashboard built using Streamlit and SQLite. It helps users track spending patterns and gain insights through interactive visualizations.

---

## 🚀 Features
- Add and manage daily expenses
- Store data using SQLite database
- Interactive dashboard using Streamlit
- Visual insights into spending patterns

---

## 🛠️ Tech Stack
- Python
- Streamlit
- SQLite

---

## 📊 Project Objective
To build a simple and interactive data-driven application that demonstrates practical use of Python, databases, and visualization tools.

---

## ▶️ How to Run

1. Clone the repository:
```bash
git clone https://github.com/vishalupadhyay1717-pixel/SpendiQ.git
```

2. Navigate to the project folder:
```bash
cd SpendiQ
```

3. Install dependencies:
```bash
pip install streamlit pandas
```

4. Run the app:
```bash
streamlit run app.py
```
